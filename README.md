# Modelling-Control-and-Simulation-of-DC-DC-Converters
Material of the book Modelling-Control-and-Simulation-of-DC-DC-Converters

By J. Marcos Alonso, University of Oviedo, Spain

Amazon KDP, 2025

ISBN:979-8278321743

Available at: https://www.amazon.com/dp/B0G6FQSGKR

This repository includes all simulation files and python scripts of the book.

Summary of the book:

This book presents how to model, control, and simulate DC-DC converters in a friendly manner. An insightful modelling technique based on the use of equivalent averaged circuits is presented and applied to the most common DC-DC converters to obtain both their static and dynamic behavior. The implementation of compensators for closed-loop operation using different technologies is also dealt with in this book. In addition, most common control methods are presented and analyzed to obtain their dynamic behavior. Finally, simulation techniques using free simulators like LTspice and Qspice are also addressed. Complicate mathematic analyses are avoided in this text so that any person with a minimum knowledge of mathematics and electronics will be able to follow the explanations and master the modelling, control, and simulation of DC-DC converters.
